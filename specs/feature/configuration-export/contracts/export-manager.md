# Export Manager Contract

## Function Signature
```javascript
function exportReportToGoogleSheets(reportData, configuration, targetFolder)
```

## Purpose
Create a new Google Sheets document with the generated report data and save it to the specified Google Drive folder.

## Input Requirements
### reportData Parameter
```javascript
{
  headers: string[],               // Column headers for the report
  rows: any[][],                   // Data rows matching headers
  summaryRow: any[]|null,          // Optional summary/totals row
  metadata: {
    generatedAt: string,           // ISO timestamp
    configurationUsed: string,     // Configuration name used
    recordCount: number,           // Number of data rows
    filterCriteria: string,        // Description of applied filters
    sortCriteria: string           // Description of applied sorting
  }
}
```

### configuration Parameter
```javascript
{
  reportName: string,              // Used for file naming
  description: string              // Used in metadata sheet
}
```

### targetFolder Parameter
- Google Drive Folder object where the report should be saved
- Must have write permissions for the current user

## Output Contract
```javascript
{
  success: boolean,
  fileId: string|null,             // Google Drive file ID if successful
  fileName: string|null,           // Name of created file
  fileUrl: string|null,            // Direct URL to the Google Sheets file
  sheetStructure: {
    "Report Data": {
      rowCount: number,            // Number of rows written
      columnCount: number          // Number of columns written
    },
    "Report Info": {
      metadata: object             // Metadata written to info sheet
    }
  },
  errors: string[],                // Creation/writing errors
  warnings: string[]               // Non-critical issues
}
```

## File Structure Requirements

### Main Sheet: "Report Data"
- **Row 1**: Column headers (bold formatting)
- **Rows 2+**: Data rows from reportData.rows
- **Last Row**: Summary row (if reportData.summaryRow exists, bold formatting)
- **Formatting**: 
  - Headers in bold with background color
  - Numeric columns right-aligned
  - Date columns formatted as dates
  - Auto-resize columns to fit content

### Information Sheet: "Report Info"
- **A1-B1**: "Report Name", configuration.reportName
- **A2-B2**: "Description", configuration.description
- **A3-B3**: "Generated At", reportData.metadata.generatedAt
- **A4-B4**: "Record Count", reportData.metadata.recordCount
- **A5-B5**: "Filter Criteria", reportData.metadata.filterCriteria
- **A6-B6**: "Sort Criteria", reportData.metadata.sortCriteria
- **A7-B7**: "Generated By", "Timesheet Configuration Export System"

## File Naming Convention
```
Format: "Report_{ConfigurationName}_{YYYY-MM-DD_HH-MM}"
Example: "Report_Monthly Summary_2025-10-24_14-30"
```

## Processing Requirements

### 1. File Creation
- Create new Google Spreadsheet with generated file name
- Place file in the specified targetFolder
- Set appropriate sharing permissions (inherit from folder)

### 2. Data Writing
- Write all data in batch operations to minimize API calls
- Handle large datasets by chunking if necessary (>1000 rows)
- Apply formatting after data is written

### 3. Sheet Configuration
- Create "Report Data" sheet as the primary sheet
- Create "Report Info" sheet as secondary sheet
- Set "Report Data" as the active sheet
- Freeze the header row for better navigation

### 4. Error Handling
- Retry file creation up to 3 times if initial attempt fails
- Validate data before writing to prevent partial corruption
- Clean up partial files if writing fails completely

## Google Apps Script Constraints
- Maximum 6 minutes execution time for the entire operation
- Maximum ~100MB memory usage
- Rate limiting on Google Sheets API calls
- Single-threaded execution (no parallel processing)

## Error Conditions
- Target folder not accessible → Return success: false with permission error
- File creation fails → Return success: false with creation error details
- Data writing fails → Return success: false, attempt to delete partial file
- Formatting fails → Return success: true with warning (data saved, formatting incomplete)
- Large dataset exceeds time limits → Return success: false with timeout error

## Performance Optimization
- Use batchUpdate operations instead of individual cell writes
- Write data in chunks of 1000 rows maximum
- Minimize API calls by preparing all data before writing
- Show progress updates for operations taking longer than 30 seconds
